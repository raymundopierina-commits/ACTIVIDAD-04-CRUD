# 🚀 ACTIVIDAD-04-CRUD

Sistema CRUD completo para gestión de productos desarrollado con **PHP**, **MySQL** y **JavaScript puro**.

![PHP Version](https://img.shields.io/badge/PHP-7.4+-blue.svg)
![MySQL](https://img.shields.io/badge/MySQL-5.7+-orange.svg)
![Status](https://img.shields.io/badge/status-activo-green.svg)

## 📋 Descripción

Aplicación web que permite realizar operaciones **CRUD** (Crear, Leer, Actualizar, Eliminar) sobre un catálogo de productos. Interfaz simplificada y responsiva.

### ✨ Características

- ✅ Listar productos con precios y estado
- ➕ Agregar nuevos productos
- ✏️ Editar productos existentes
- 🗑️ Eliminar productos
- 🎨 Interfaz limpia y moderna
- 📱 Diseño responsivo

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| **PHP** | Backend y lógica de negocio |
| **MySQL** | Base de datos |
| **HTML5/CSS3** | Estructura y estilos |
| **JavaScript** | Interactividad y peticiones AJAX |
| **Git/GitHub** | Control de versiones |
